Train Seat Reservation System

Designed and implemented a reservation system for a single-coach train with 80 seats.
Each row contains 7 seats, with the last row having 3 seats.
Allowed users to book up to 7 seats at a time, prioritizing consecutive seat allocation in the same row.
Developed logic to ensure nearby seat allocation if a single row could not accommodate the requested seats.
Displayed seat availability dynamically, using colors or numbers to indicate booked and available seats.
Enabled seamless user interaction to book tickets until the coach was fully booked.
Focused on an intuitive user interface and efficient seat management.
